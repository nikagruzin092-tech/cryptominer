# TON Falcon 2.0

Это серверная версия твоего Mini App: баланс, энергия, прокачка, daily, rewarded-награда и заявки на вывод хранятся на сервере, а не в localStorage.

## Запуск

1. Установи Node.js 20+.
2. В папке проекта выполни:
   npm install
3. Создай `.env` на основе `.env.example`.
4. Укажи BOT_TOKEN своего Telegram-бота.
5. Запусти:
   npm start

Для Telegram Mini App нужен HTTPS-адрес. Локальный `http://localhost` для обычного запуска Telegram не подходит.

## Важно про AdsGram

`ADS_BLOCK_ID` должен быть реальным Rewarded block ID из твоего кабинета AdsGram. В `public/app.js` сейчас оставлен 47176 как пример из твоего проекта.

## Важно про вывод

Версия 2.0 создаёт серверную заявку `pending`, но НЕ отправляет TON автоматически. Реальные выплаты нужно подключить отдельно и только после проверки заявки. Не обещай пользователям автоматические выплаты, пока эта часть реально не подключена.

## Безопасность

Никогда не помещай BOT_TOKEN в `public/app.js`. Сервер проверяет Telegram initData и хранит баланс в SQLite.
